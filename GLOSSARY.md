# AMS Glossary

Shared meanings used by these templates. The AMS definition follows Kayden's 2026-10-31 instruction; record distinctions follow the [research basis](workbench/research/template-research-basis.md).

| Term | Meaning and distinction |
|---|---|
| AMS | Kayden's system for managing agents, workflows, intent capture, skills and AI tools in one RSI loop, built on and operating the Workbench while repairing it. |
| RSI loop | Recursive self-improvement through actual work: observe friction, propose a bounded change, compare outcomes, decide its disposition and examine later use. A loop record does not prove improvement. |
| Workbench | The working foundation AMS uses and repairs; AMS also encompasses the system and tool belt that operates above it. |
| Intent | What the owner wants, with reasons, boundaries and corrections; retain whether it is confirmed or unresolved. |
| Implementation Task | A bounded assigned slice under a Spec, owning execution state and proof. |
| Evaluation task / trial | A repeatable test case / one attempt at it. Neither is an implementation assignment. |
| Evidence audit | A maintained assessment of claims against dated, candidate-specific evidence, preserving reassessment history. |
| Improvement record | The connection from an observed problem through a hypothesis and comparison to an actual disposition and later-use check. |
| Review receipt | An actual assessment of a named candidate and scope, recording reviewer involvement, findings and limits. |
| Human QA receipt | Sourced human judgment of the named experience/candidate; agent checks cannot supply it. |

## Feedback dispositions

These describe how a finding was handled; they grant no execution or release authority.

| Value | Required supporting reference |
|---|---|
| diagnostic | Named diagnostic that makes the condition visible; record whether it is implemented or proposed. |
| test | Named test that detects the condition, with its actual result or implementation gap. |
| repaired | Implementing revision and relevant verification; later-use benefit remains a separate claim. |
| declined | Actual decision source and reason for declining the proposed action. |
| accepted-open | Actual acceptance of follow-up work and its owning Spec; the problem remains open. |

If no disposition is established, keep it pending with the missing owner/evidence stated. Do not invent a choice to make a report look complete.
