# One improvement procedure, starting from failed results

There is one improvement procedure. For now it starts only from failed results. It changes one owner, reruns the same tasks, and ends in a ledger row plus a disposition: retain, revise or remove. A retro is for the owner to find rough spots; not every retro finding becomes an improvement.

Considered and rejected: starting improvements from every retro finding. The retro loop itself needs improving before it is used in force.

Consequences: Retro findings reach the loop only through a failed result.

Provenance: Owner decision review, 2026-11-01, with the owner's correction.
