# A prototype needs no Spec

A prototype needs no Spec. What the owner decides from it becomes a CDR. Its code enters the product only through tests and review.

Considered and rejected: shipping prototype code directly, or requiring a Spec to explore.

Consequences: Prototype decisions are recorded as CDRs.

Provenance: Owner decision review, 2026-11-01.
