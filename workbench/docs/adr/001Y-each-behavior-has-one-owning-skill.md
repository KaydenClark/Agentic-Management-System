# Each behavior has one owning skill

Each behavior has one owning skill that others call, not copy. A called skill inherits exactly the caller's scope.

Considered and rejected: copying procedure text between skills.

Consequences: A called skill never widens the caller's authority.

Provenance: Owner decision review, 2026-11-01.
