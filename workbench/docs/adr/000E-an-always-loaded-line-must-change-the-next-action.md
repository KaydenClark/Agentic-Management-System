# An always-loaded line must change the next action

An always-loaded line stays only if it changes an agent's next action. Size is measured in loaded tokens, not words. Size targets warn and never split files.

Considered and rejected: long instruction files; IFScale shows models follow only part of a large instruction set.

Consequences: Budgets report over-size controls for revision; see the character-limit record.

Provenance: Owner decision review, 2026-11-01.
