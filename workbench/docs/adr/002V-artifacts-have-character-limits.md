# Artifacts have character limits

Root controls target 900 to 1,500 characters, with a limit of 3,000. Specs, Tasks and Landmarks have a limit of 8,000. An over-limit file goes back to its author for pruning and revision until it fits. It is never split into parts and never truncated.

Considered and rejected: splitting large files into parts, which produced thousands of fragments in an earlier room.

Consequences: The budget file carries the numbers.

Provenance: Owner decision review, 2026-11-01.
