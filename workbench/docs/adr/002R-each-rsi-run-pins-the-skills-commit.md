# Each RSI run pins the skills commit

Each RSI run records the commit of the skills it used. Skill copies must stay current and nothing may fall behind; the Coherence orchestrator checks that the project stays up to Spec.

Considered and rejected: unpinned skills, which make runs incomparable, since personal skills do not reach cloud sessions.

Consequences: Ledger rows carry the skills commit.

Provenance: Owner decision review, 2026-11-01, with the owner's correction.
