# Improvement claims need held-out ledger evidence

No document, site page or report claims the AMS improves outcomes unless held-out ledger rows support it: repeated trials, controls, the prior version and an interval.

Considered and rejected: citing static scores, shorter prompts or a single successful demo as improvement.

Consequences: The site links each claim to the rows that support it, at the scope they support.
