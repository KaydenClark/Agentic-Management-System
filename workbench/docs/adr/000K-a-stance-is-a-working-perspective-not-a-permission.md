# A stance is a working perspective, not a permission

A stance is a perspective given to an agent while it works, to make it more effective at that work. A stance grants no permission and does not make the same context an independent reviewer.

Considered and rejected: treating a stance as authority or as independence.

Consequences: The Glossary carries this definition; review independence comes from a fresh context.
