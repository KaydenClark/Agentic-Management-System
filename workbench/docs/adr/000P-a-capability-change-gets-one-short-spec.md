# A capability change gets one short Spec

A named capability change gets one short Spec. Small edits need none. Tasks are vertical slices.

Considered and rejected: Specs for every edit, or horizontal Tasks by layer.

Consequences: Plan cuts each Spec into vertical Tasks.
