# Done requires a pushed, read-back commit

`done` refuses unless the result commit is pushed and the remote branch, read back, contains it.

Considered and rejected: trusting a local commit as delivered.

Consequences: Delivery reports name the remote commit.

Provenance: Owner decision review, 2026-11-01.
