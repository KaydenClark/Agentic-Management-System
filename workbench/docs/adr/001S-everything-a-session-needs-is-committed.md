# Everything a session needs is committed

Everything a session needs to continue is committed. Skills come from the owner's skills repository, and a cloud session must be able to install them.

Considered and rejected: relying on files that exist only on one machine.

Consequences: Cloud sessions install skills from the skills repository.

Provenance: Owner decision review, 2026-11-01.
