# Read commands use the same words for every kind

CLI read commands use the same words for every kind of record: list, show, search, history, inspect.

Considered and rejected: per-kind verbs that agents must learn separately.

Consequences: New record kinds answer the same five words.

Provenance: Owner decision review, 2026-11-01.
