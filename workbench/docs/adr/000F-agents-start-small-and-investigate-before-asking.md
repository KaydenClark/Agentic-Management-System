# Agents start small and investigate before asking

Agents start from AGENTS.md and the assigned work, load more only as needed, investigate before asking, and record a real blocker instead of inventing work.

Considered and rejected: loading everything at start, or asking the owner what the repository already answers.

Consequences: A blocker is recorded where the owner will see it.

Provenance: Owner decision review, 2026-11-01.
