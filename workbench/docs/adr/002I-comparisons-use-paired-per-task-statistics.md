# Comparisons use paired per-task statistics

Comparisons are paired per task. The minimum effect and the reducer are fixed in advance: pass^3 for reliability and mean per-task success for A/B. Verdicts include inconclusive, unreliable, pre-existing and blocked.

Considered and rejected: unpaired pass rates with loose confidence intervals.

Consequences: The small-sample test is researched before the first comparison.
