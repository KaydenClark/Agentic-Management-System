# A rule is enforced only when code refuses and a test shows it

A rule is called enforced only when running code refuses the operation and a test shows the refusal. Code checks structure; agents carry judgment.

Considered and rejected: calling a declared policy or a config field enforcement.

Consequences: Reports say "enforced" only with the refusing check and its test.
