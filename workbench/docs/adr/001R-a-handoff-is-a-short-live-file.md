# A handoff is a short live file

A handoff is a short file stating the endpoint, state, open question and next action. It is committed on the work branch while live and deleted afterwards.

Considered and rejected: long handoffs that restate the records.

Consequences: A handoff is removed in the change that completes it.

Provenance: Owner decision review, 2026-11-01.
