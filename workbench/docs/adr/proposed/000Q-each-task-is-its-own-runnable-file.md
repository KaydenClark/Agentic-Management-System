# Each Task is its own runnable file

Each Task is its own file, runnable from a clean clone using only the Task, the Spec and the files it cites.

Considered and rejected: Tasks that depend on chat history or another session's context.

Consequences: A Task names every file it relies on.

Provenance: Owner decision review, 2026-11-01.
