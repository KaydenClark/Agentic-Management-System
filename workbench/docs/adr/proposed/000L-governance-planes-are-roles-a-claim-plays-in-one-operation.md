# Governance planes are roles a claim plays in one operation

The governance planes (wanted, authoritative, exists, proven, known, shown) name the role a claim plays in one operation, never a folder.

This is a hypothesis. The owner confirmed it as a working rule, and the RSI loop tests whether it holds. Confirmed if on tasks where Spec, code and a dashboard disagree, agents given the vocabulary name gaps, drift and ambiguity correctly and over-claim completion less often than agents without it. Refuted if there is no difference, or the same score costs more tokens.

Considered and rejected: folders or file types named after planes.

Consequences: The Glossary defines the six roles.
