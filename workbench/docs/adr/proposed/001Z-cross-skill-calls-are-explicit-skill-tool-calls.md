# Cross-skill calls are explicit Skill-tool calls

Cross-skill calls are written as explicit Skill-tool calls.

This is a hypothesis. The owner confirmed it as a working rule, and the RSI loop tests whether it holds. Confirmed if on the same tasks, explicit wording shows a higher rate of actual Skill-tool invocation and a higher pass rate than a bare mention. Refuted if there is no difference.

Considered and rejected: slash-command prose that agents may not act on.

Consequences: Transcripts are checked for actual invocation.

Provenance: Owner decision review, 2026-11-01.
