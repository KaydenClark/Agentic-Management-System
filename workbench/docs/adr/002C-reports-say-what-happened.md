# Reports say what happened

Reports say what happened: implemented, partial, planned or blocked. A baseline that cannot run is recorded as unavailable, never as a pass. A measured failure is never relabeled unavailable.

Considered and rejected: manufactured scores or skipped steps reported as done.

Consequences: Every report uses these four states.
