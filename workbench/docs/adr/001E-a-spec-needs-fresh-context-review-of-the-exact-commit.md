# A Spec needs fresh-context review of the exact commit

A Spec is accepted only after a fresh-context reviewer passes the exact assembled commit against the Spec's conditions. A changed commit needs a fresh review. A different agent name in the same session is not independence. Tasks get checks plus the builder's QA, not independent review.

Considered and rejected: self-review, or review of a commit other than the one delivered.

Consequences: Review receipts name the commit reviewed.

Provenance: Owner decision review, 2026-11-01.
