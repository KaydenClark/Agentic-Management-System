# Landmarks are the PRDs

A landmark is a big destination, used as a PRD. A Spec is a smaller destination on the way to a landmark, and a Task is a small step toward a Spec. The first four landmarks are the Grill Board, the presentation of the RSI, the AMS website, and running the RSI loop while the website is built.

Considered and rejected: leaving landmarks empty. The owner rejected the argument that something unbuilt is evidence against it, since nothing in a new project is built yet.

Consequences: Each Spec names its landmark.

Provenance: Owner answer, 2026-11-01 (round 2).
