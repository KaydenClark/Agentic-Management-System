# Setup drafts the Blueprint and starts a grilling

When the AMS is set up in a project, it drafts the Blueprint and any records the existing material supports, marks them unconfirmed, and starts a grilling.

Considered and rejected: blank setup that leaves the owner to write everything, or drafts treated as confirmed.

Consequences: Drafted records stay unconfirmed until the owner confirms or corrects them.

Provenance: Owner decision review, 2026-11-01.
