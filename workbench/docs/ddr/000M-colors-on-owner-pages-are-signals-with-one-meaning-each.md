# Colors on owner pages are signals with one meaning each

Colors on owner-facing pages are signals. Each color has one stated meaning. There is no fixed number of hues.

Considered and rejected: exactly five hues; the earlier board already had a sixth, so the fixed count was wrong.

Consequences: Each page states its color meanings, and a color never carries two.

Provenance: Owner decision review, 2026-11-01, with the owner's correction.
