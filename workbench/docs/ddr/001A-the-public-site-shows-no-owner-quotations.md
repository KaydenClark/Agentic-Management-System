# The public site shows no owner quotations

The public website never shows the owner's words as quotations and never uses the owner's actual instructions or commands to agents as examples. Where a page depends on an owner decision, it paraphrases the decision and links its source record.

Considered and rejected: showing owner words verbatim with a dated source link, the earlier rule in S-003 and S-005, which the owner withdrew.

Consequences: S-003 and S-005 state the rule and drop the verbatim-with-source rule. Internal records may still hold sourced owner wording; only what visitors see changes. Site conventions and tests that admit owner quotations are site work on `dev`.

Provenance: Owner decision in chat, 2026-11-02, relayed by the coordinating session; paraphrased in `workbench/wiki/context-website-presentation.md` (JOT-90878239).
