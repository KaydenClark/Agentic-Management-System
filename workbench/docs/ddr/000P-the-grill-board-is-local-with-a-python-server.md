# The Grill Board is local, with a Python server

The real Grill Board runs only on the owner's machine, served by Python. It is the owner's attention queue: agents post items that need his answer, he answers and rates there, and agents apply the verdict to the durable owner. It is not a drafting surface.

Considered and rejected: hosting the Grill Board on Vercel.

Consequences: The public site shows only a demo board.

Provenance: Owner answer, 2026-11-01 (round 2). Owner answer, 2026-11-01 (round 3).
