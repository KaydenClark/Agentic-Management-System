# Delivery runs in rounds the owner approves or returns

Delivery runs in rounds: agents carry a confirmed concept to a result; the owner approves it or sends it back with what is wrong; the next round starts from that answer.

Considered and rejected: calling this loop "recursive", which would imply the measured self-improvement that only the RSI loop can claim.

Consequences: The product loop (rounds) and the system loop (RSI) are named differently.

Provenance: Owner decision review, 2026-11-01.
