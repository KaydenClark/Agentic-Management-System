# Every card carries Priority and Value grades

Each question card carries separate Priority and Value grades, each with a one-line reason. They stay on every card. This is the owner's system for telling what needs his attention, and it has no drop condition.

Considered and rejected: treating the grades as a hypothesis to drop if they cluster or go unused; the owner corrected this.

Consequences: The board always shows and filters by both grades; they are never summed.

Provenance: Owner decision review, 2026-11-01, with the owner's correction.
