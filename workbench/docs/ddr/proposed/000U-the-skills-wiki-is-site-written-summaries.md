# The skills wiki is site-written summaries

The site's skills wiki shows summaries the site writes about the owner's skills, modeled on https://www.aihero.dev/skills. It does not publish the skills' own text.

Considered and rejected: publishing the private skills repository's content.

Consequences: Summaries are drafted by agents and approved by the owner.
