# The AMS is the owner's agent-management system

The AMS is the management system Claude Code and Codex use to align the owner's ideas and deliver them. "Harness" means a provider's agent runtime and never names the AMS.

Considered and rejected: calling the AMS a harness, which blurs what the AMS changes with what the provider ships.

Consequences: Documents, the site and reports say "the AMS"; the Glossary defines both terms.

Provenance: Owner decision review, 2026-11-01.
