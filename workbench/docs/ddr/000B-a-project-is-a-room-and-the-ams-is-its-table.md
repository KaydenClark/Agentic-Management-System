# A project is a room and the AMS is its table

A project is a room and the AMS is the table in it: the rules, tools and records agents use while the project stays at the center. The AMS proves itself on an external product, the public site, never on itself.

Considered and rejected: proving the AMS by having it build or audit itself, which grades its own ceremony instead of a product outcome.

Consequences: The site is the AMS's first proving project; release evidence comes from building it.
