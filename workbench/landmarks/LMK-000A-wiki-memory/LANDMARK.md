## Direction

The Wiki is AMS's knowledge base and memory: agents recover established understanding, owner intent and corrections, reasons, constraints, unresolved context and routes to current owners before acting. They build on prior knowledge instead of reconstructing chronology every session. [The owner's correction](../../wiki/context-wiki-maintenance.md#jot-b3247909-9721-4842-a83f-61adc5da2e13) explicitly makes this its own Landmark, independent of RSI. Historical S-000C placement is provenance, not current capability classification.

## Why It Matters

Captures alone do not supply maintained understanding. Navigation and bounded retrieval must expose relevant explanations and evidence, distinguish current from superseded claims, and support safe consolidation. A structural validator cannot prove an agent remembered correctly.

## What Success Looks Like

- [ ] An agent starting fresh recovers useful established context and live owner routes with bounded evidence, uncertainty and corrections.
- [ ] Retrieval covers maintained sections, Jots and source references while preserving context and privacy.
- [ ] Source changes identify affected claim explanations for review without silently rewriting knowledge.
- [ ] Supported consolidation improves the existing owner and affected routes while retaining original evidence and exact confirmations.
- [ ] Different task needs receive appropriate memory functions and detail, without new governance planes or copied live state.
- [ ] Real AMS functional evaluations expose wrong answers, missed sources, stale repetition and unknowns; actual context size and owner effort remain distinguishable from unmeasured values.

## Boundaries

Git and Markdown remain durable sources. Derived indexes are rebuildable and grant no authority. Preserve the six claim planes, read-only sources, privacy, source lineage and scoped execution/delivery approvals. No paid services, database migrations, shared-skill changes/installations, deployment or unrelated upgrades. Wiki evaluation is functional acceptance, not RSI qualification.

## Verification Procedure

Use S-000D's public CLI acceptance examples, real AMS question set and fresh-agent correction exercise. Independently judge answer/source fidelity against pinned sources; report unavailable checks and unmeasured human effort. Native structure checks supplement behavioral evidence.
