# Shared skills refocus: purpose, composition and preparation

## Confirmed direction

Source: Kayden's answers in this AMS chat, 2026-11-02. The catalog should teach specificity that changes behavior: decisions, techniques, checks or reusable assets for recognizable jobs. Greater reliability is valuable even without a new capability. Improve existing workflows while preserving their purpose and useful responsibilities.

Diagnosing Bugs and Plan are the two pilots. Diagnosing Bugs may return an unresolved cause when it supplies the evidence and a useful next discriminating experiment. Plan must continue slicing a Spec into vertical agent assignments: each Task advances the destination, fits complete investigation/implementation/verification/repair/return within the implementor's smart zone, and has real blocking relationships. Independent ready Tasks can run in parallel with safe writer boundaries. Do not turn this into a different workflow or use task size to excuse incomplete objectives.

Skills may execute other skills. Extract a shared method when it serves a distinct reusable job; teach callers when to use it, its inputs, expected result, verification and failure handling. Pruning is the agreed example. Existing independent-pruner requirements still apply. A reference, route to a next skill or citation is not execution of that skill.

Only two composition labels are wanted: Primitive executes no other skills; Compound executes one or more, including conditional execution. Workbench dependency is separate: label required when normal operation needs artifacts, machinery, conventions or required helpers established by setup-workbench. Trace actual helper paths, not names alone. No new nested discovery directories are requested.

Attribution does not prevent adaptation. Preserve original author/source, applicable notices and evolution history; explain what was inspired by or adapted from the source without misrepresenting the current author or method. Imported skills are eligible for improvement. Consolidation or retirement requires explicit owner approval and good evidence of non-use, unhelpfulness or a better replacement that accounts for useful responsibilities. No usage telemetry is not evidence of no use.
